# Rechard 问题交接模板

每个问题单独一段，文件与截图放在本次 `runs/<模板>-<日期>/backend-evidence/`。

```markdown
## <序号> <简短标题>

- 模板：`<id>`
- 来源页面：`<完整 URL>`，HTTP `<状态>`
- 点击入口：`<页面位置与可见文字>`
- 目标路径：`<路径或完整 URL>`
- 实际结果：HTTP `<状态>`
- 异常：`<异常类型与消息>`
- 代码位置/责任层：`<run.py/cache/api/...>` / 后端
- 复现时间：`<含时区>`
- 处理状态：等待用户协调 Rechard
- 来源截图：`<入口已红框、显示目标路径的图片>`
- 错误截图：`<目标错误页图片>`
```

若 HEAD 失败但浏览器 GET 正常，改记为“服务端方法差异”，附 GET 200 证据，不作为用户点击故障。
