# Pony TDK 手动工作台

现行范围只到“把当次 TDK 填入对应上站表行并回读确认”。旧的采购监听、后台回填和提交说明保留于 SESSION_NOTES.md 作为历史，均不是当前工作台功能。后续上站步骤由用户手动处理。

## 每次上站前

1. 读取最新 bing 指数词汇总 工作簿（1-3DvtAhJQu83G9fA1TWrEZIKiosOzvwDWYknEFXKGJ0），核对当次日期、bing体育品牌词 页中的关键词分组及 Pony 实际归属。关键词分组与模板分组不可混淆。分配没有 Pony、日期已过期或表格含糊时记录“待分配”；不能拿旧截图的 z/k/x/t 或默认 all 代替。
2. 读取本次分配词、现有网站真实页面能力，并检查相关竞争网站的最新页面或 Bing 查询结果。排名数据All 可帮助找候选竞品，但旧抓取不等于当天已核实。保存参考网址与核对日期。AI 自行撰写 Title、Description、Keywords；不直接抓取竞品 TDK 充当原创文案，也不编造直播质量、官方身份或其他站点能力。
3. 以每次上站批次为单位建立新稿。同日再次上站也要重写；比较本批和历史批次的三项文案，逐字段拒绝完全相同或仅标点/空格不同的内容。历史指纹存于 data/tdk-fingerprints.json，并随工具仓库交付。Leo 审核只在当次明确要求时生效；2026-09-18 这批属于要求审核的特例。

新稿由当前对话中的 AI 按上述来源撰写、校验并放入本批本地台账；工作台不会无依据地生成固定句式。2026-09-18 本批 20 份已填，不因新规则被重写。当前截图的 9月14日–19日分配区未见 Pony；用户刚入职，不能推断当天归属，下一批须重新核实。

## 工作台唯一写入动作

启动 ./Start-Workbench.ps1，打开 http://127.0.0.1:8766/。工作台不在后台轮询，不自行定时创建任务；由用户对话触发当批工作。Google 表格使用普通持久化浏览器，不用无痕/访客。

点击“确认写入本批 TDK”时，程序只处理已确认的 Pony 域名：核对批次日期、域名/归属/分配词、当次文案版本及查重结果；写入 Bing 上站表工作簿 1y7VWR6T4ABcd09qa51GM5-7XXGC80w1h21wCL4stvUg 的 gid=2066853497。仅写 E:H（Template、Title、Description、Keywords），按域名逐行匹配；已有不同人工内容则停止。写后回读并核对 A:D 与 I:P 未被修改。参考关键词工作簿始终只读。

工作台完成 E:H 回读后即停止本次动作，不读取/复制 Q 列脚本、不打开后台、不提交网站、不验证上线。当前批次台账在 runs/site-launch/2026-09-18-pony-20/state.json；新批次通过启动参数 -State 指定独立台账，不自动续用旧日期。写入回执位于批次目录，历史文案只以指纹形式跟踪并在工具仓库提交。
