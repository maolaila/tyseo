## 交付内容

- 共用标准与TaskSpec分离，新增existing_only页面范围；规划器以x66等其他编号通过合成测试，未创建或修改该编号业务模板。
- 全页320、无JS双系统配色、文本字号翻倍/字距压力、关键断点与横屏计划；执行器补齐相应DOM压力与WebKit/Firefox双尺寸双主题。真实浏览器缩放/真机键盘仍单列能力缺口。

- CLS按会话窗口记录且排除最近用户输入；读取时间在截图禁用动画之前，人工文字压力不参与正常CLS失败判定。无API支持不冒记0分。
- 最终门禁逐项核对checks/证据/hash/政策版本。工具没运行、漏项、明确失败留在工具队列；只有明确review_triggers或工具疑点进入AI队列。完整工具证据可免AI重复检查。删掉required_checks、证据变化或旧输入均不能放行。

## 已知限制

现有matrix-results与通用capture-records仍需半自动按case_id、HTTP/DOM/截图和checks整理。不能批量把needs_review改pass。点击命中只测当前视口；伪元素、shadow DOM、iframe内部、复杂对比度、所有滚动/焦点/浮层状态、真实缩放/真机、语义和未知生产配置仍需相应工具补采或AI处理。

没有重跑所有z1–z17的新v2完整矩阵；旧证据不升级。76/84等测试数量反映工具实现，不代表页面/公司/上线验收。新版标准与策略不自动触发业务修复、域名工作流、机器人或发布。
