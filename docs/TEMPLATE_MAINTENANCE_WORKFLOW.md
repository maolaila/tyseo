# 模板维护与验收工作流程

适用于已有模板的修复、个人模板开发后的验证和上站前复查。页面、数据和后端由同一业务服务提供时，模板只负责自己的 HTML、CSS、JS 与入口；不通过模板伪造数据、绕过路由或修改 Python。

## 1. 开始前

1. 阅读当前任务、`AGENTS.md`、最新相关聊天记录、现行验收标准和当前 Git 状态。
2. 锁定要验证的模板分支和提交。与正在人工验收的其他模板分支不同的模板，必须使用隔离工作树和独立端口。
3. 保留 HeaderJS/FooterJS、jQuery、ajs.js 等动态插入与下载能力；测试中不将本地配置缺少的动态内容当作已通过。
4. 每次测试新建运行目录，记录模板、提交、端口、页面样例来源、执行时间和源码指纹。

## 2. 页面、路由与入口分类

先从真实返回 200 的页面抓取用户可点击的站内链接，逐个用浏览器 GET 验证。当前真实入口能点击到的页面是用户体验验收的优先范围。

代码中存在模板或路由、但当前页面没有入口/样例时，不能直接叫“历史垃圾代码”或删除。按以下顺序分类：

1. 核对 `run.py` 路由、参数格式和所需真实 ID、拼音、年份等数据前提。
2. 检查其他 z 模板是否有同一功能入口，并请求已确认的真实路径。
3. 页面存在、路由 GET 为 200、同系列模板也提供该功能时，在本模板的共用导航或对应组件补入口，并测试入口、目标页和选中状态。
4. 参数/数据缺失、没有真实样例时记为 `blocked`，保留待验证，不编造 URL。
5. 路由或数据服务报错时按后端问题登记；只有已确认无路由、无产品用途且获得明确清理决定时，才可作为历史代码移除。

## 3. 404、500 与请求方法

- 所有用户实际点击路径必须以浏览器或 GET 结果判定；404、500、错误跳转都不能通过。
- 审计器可用 HEAD 做快速初查，但 HEAD 失败必须再以 GET 复核。HEAD 失败而浏览器 GET 正常时，登记为服务端方法差异，不记为用户页面故障。
- `TemplateNotFound`、模板内异常、链接地址/参数错误属于前端范围；`run.py`、`cache/`、`api/`、数据库或外部数据连接异常属于后端范围。不能在前端伪造成功页。
- 每个需要后端确认的问题必须落盘：模板编号、来源完整地址、被点击元素文字与位置、目标路径、HTTP 状态、异常/代码位置、复现时间、责任层。
- 每条保留两张图：来源页将实际入口红框标出并显示目标路径；目标错误页显示状态和异常。由用户统一协调 Rechard，未经授权不自动外发。

## 4. 页面加载完成后的功能与视觉验收

页面先等待加载完成和必要资源稳定，再判断最终用户可见状态。CLS 作为诊断记录；当前维护策略以加载完成后的可读性、可操作性和无跑版为放行条件。

- 桌面 1280、手机 390 至少覆盖明暗主题；需要时补 320、768、1920、无 JS、Firefox/WebKit。
- 实际操作搜索、主题刷新保持、手机抽屉开关/Esc/遮罩、返回顶部、分页、页签、筛选、下拉、排序和页面专有控件。仅高亮变化不算功能通过，必须核对结果内容、可见行、URL 或目标页面。
- 检查加载完成后无整页横向溢出、内容遮盖、关键文字裁切、表格表头透出/被数据行覆盖、主操作无法点击；允许设计明确的局部表格滚动。
- 图片、Logo、长队名、三位数比分、空数据和失败资源不能造成最终布局破坏。不可判断的控件或缺数据页面保留 `needs_review`/`blocked`。

## 5. 结果与人工验收

1. 结果分为 `pass`、`fail`、`blocked`、`needs_review`，不将缺样例、后端问题或未执行项目写成通过。
2. 前端可修问题完成后，只重跑受影响页面与共用组件宿主；链接、导航或共用母版改动需要重跑相关真实入口检查。
3. 提交前检查修改只在授权模板目录，提交后推送并核对远程 SHA。
4. 启动本地页面供人工验收时，说明模板分支、URL、已验证范围、后端待确认清单和未覆盖项。人工验收、合并、部署、上站和搜索引擎效果始终单独记录。

## 6. 个人模板复用

个人模板与当前上站模板分开管理。个人模板测试可借用已确认的 z1 真实页面路径，因为后端路由和数据服务共用；仍须确认响应确实加载目标模板的静态资源。测试结果只证明该提交的本地模板，不证明线上已部署或可用于上站。

完整可执行清单见 [模板通用测试用例](TEMPLATE_TEST_CASES.md)，每次测试以 [测试报告模板](TEMPLATE_TEST_REPORT_TEMPLATE.md) 交付；后端问题使用 [Rechard 问题交接模板](TEMPLATE_ISSUE_HANDOFF_TEMPLATE.md)。
