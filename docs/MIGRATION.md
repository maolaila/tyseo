# 换机与加密数据恢复

工具仓库：https://github.com/maolaila/tyseo.git （本次核验为公开）。公司源代码不镜像到本仓库。

## 首次迁移

1. 在新电脑安装 Git、Python 3.10，取得公司业务仓库的访问权限；克隆本工具库。
2. 单独安全转移 `tyseo-migration.key`。密钥不在Git里，不要与密文一起上传。
3. 在工具目录运行：

```powershell
.\Initialize.ps1 -BusinessRepo C:\tyseo\cms-sport-tpl-bing -RestoreData -KeyFile <单独转移的密钥路径>
```

入口安装外部依赖/浏览器并将证据、草稿、私有配置恢复到 `restored/`，拒绝覆盖现有文件。公司项目仍使用自己的Python环境和权限；本脚本不重新配置白名单、不安装或修改公司依赖、不覆盖现有.env。

恢复的 `.env` 和本地需求记录位于 `restored/private/business/`；只有在新电脑明确配置业务环境时再使用，不能盲目覆盖已存在的配置。路径与IP相关设置须按新电脑实际情况核验。后台账号若纳入包，位于 private/ 内，不打印到终端。

## 上传范围

- Git直接保存：工具源码、规则、文档、测试、锁文件、迁移脚本与配置。
- AES-256-GCM加密分片保存：runs证据/原始响应/日志/截图、外部草稿与fixture、tySEO .env 及本地需求记录。每片25MiB，清单带SHA-256；验证GCM认证后才解压。
- 不上传虚拟环境、浏览器安装包、浏览器个人登录配置、其他项目凭据，也不复制公司源码。依赖由锁文件重建。
- 公开仓库中只有密文，没有凭据明文或解密密钥。Git凭据、公司仓库权限与白名单不是可以安全塞进公开仓库的“一键免登录”替代品。

密钥丢失无法从Git恢复。不要将当前迁移密钥复制到本仓库；未来用户切换全自动机器人时仍要由独立秘密存储提供解密能力。
