# 模板通用测试用例

适用于每个新开发或接手修改的模板。**功能分母以业务仓库当前 r62 为基线**：先盘点 r62 实际存在的页面、链接和控件，再验证目标模板的等价实现；r62 没有的搜索、主题切换、回顶等不能作为通用必备功能。目标模板自行增加的功能仍要测试，但属于该模板自有用例，不能反向扩大所有模板的功能范围。手机抽屉是明确的强制例外，不因 r62 当前是否具备而取消。

每次以当前提交、新建运行目录和真实本地预览执行；模板编号、r62 基线提交、页面样例、数据状态和证据路径写入报告。无真实样例、后端错误、工具不能判断的项目分别标 `blocked` 或 `needs_review`，不得写成通过。

## A. 测试前置

|编号|检查|通过条件|证据|
|---|---|---|---|
|PRE-01|范围与提交|目标分支、SHA、授权目录、工作树状态明确|Git 状态与 SHA|
|PRE-02|模板选择|页面响应确实引用目标 `static/<id>/`|首页与内页原始 HTML|
|PRE-03|页面清单|列出真实入口、模板文件、路由、参数前提和缺样例页|页面契约/清单|
|PRE-04|动态保留|HeaderJS、FooterJS、jQuery、ajs.js 和 APP 下载入口未被移除|母版源码与渲染 HTML|
|PRE-05|r62 功能基线|记录当前 r62 提交与页面/控件清单；目标测试项能对应到 r62 源码或目标模板自有功能|Git SHA、r62 源码位置、功能映射|

## B. 真实入口与路由

|编号|检查|通过条件|
|---|---|---|
|ROUTE-01|首页与主导航|首页、频道、联赛、列表、详情、球队/球员、视频/录像/集锦等 r62 当前可点击入口均 GET 200|
|ROUTE-02|全站内链|从真实 200 页面抓取的每个站内目标以 GET 或浏览器实际点击验证；无 404、500、错误跳转|
|ROUTE-03|分页与更多|首末页、当前页、下一页、查看更多和下拉中的真实目标均可达|
|ROUTE-04|参数页|球队、球员、比赛、标签、联赛、年份等真实参数路径可达；不猜测 URL|
|ROUTE-05|HEAD 复核|HEAD 非 2xx/3xx 必须再以 GET/浏览器复核；只记实际用户路径故障|
|ROUTE-06|未链接页面分类|代码页无样例时按“参数/数据缺失、路由未确认、后端失败、同类模板缺入口、明确历史清理”分类；不能直接删除|

## C. 基础功能

|编号|检查|通过条件|
|---|---|---|
|FUNC-01|桌面主导航|r62 母版中的首页、频道、联赛、视频、录像、集锦等真实链接可打开正确目标|
|FUNC-02|更多赛事|“更多赛事”可展开/关闭，`aria-expanded` 与可见状态一致，菜单链接可达|
|FUNC-03|手机抽屉|390 宽点击汉堡后在当前页打开抽屉/浮层；地址不变、内部链接可点，并能用关闭按钮、遮罩、Esc 或再次点击关闭|
|FUNC-04|首页赛事切换|r62 首页赛事分类逐项切换，目标比赛区可见且其他区隐藏；链接型分类打开正确页面|
|FUNC-05|首页内容切换|专题、排行、热门球队、视频等 r62 实际存在的切换控件逐项验证内容变化|
|FUNC-06|内页栏目|左侧栏目展开/收起及手机二级栏目筛选按 r62 实际控件验证|
|FUNC-07|页签与下拉|球队、球员、比赛详情等 r62 实际页签/下拉逐项切换，核对可见内容、结果集、URL 或目标页面；仅高亮不算通过|
|FUNC-08|筛选/排序|r62 实际存在的年份、赛事、主客场、转会方向、场次、联赛、球队及表格排序逐项验证；不存在的组合不编造|
|FUNC-09|展开与轮播|r62 实际存在的查看更多、收起、轮播前后按钮等控件结果正确|
|FUNC-10|直播站跳转|直播内页“观看直播”等 `/play/<type>/<id>` 链接可打开直播站目标，新窗口链接安全属性保持|
|FUNC-11|目标模板自有功能|仅对目标模板超出 r62 的真实功能追加用例；不把它提升为其他模板的公共要求|

## D. 加载完成后的布局与可读性

每个真实页面至少覆盖 1280 和 390 的 r62 默认视觉状态；关键页补 320、768、1440/1920、无 JS、Firefox/WebKit。只有目标模板实际提供主题切换时才追加明/暗主题状态。CLS 记录为诊断，当前维护放行以加载完成后的最终状态为准。

|编号|检查|通过条件|
|---|---|---|
|LAYOUT-01|整页边界|无横向溢出、白屏、内容跑出容器或页面被固定层遮挡|
|LAYOUT-02|文本与媒体|长队名、长标题、三位数比分、空数据、坏 Logo/图片后，关键内容仍可读|
|LAYOUT-03|表格|表头在顶/中/底局部滚动时不透出、不被行覆盖；允许明确的表内横向滚动|
|LAYOUT-04|交互状态|打开抽屉、下拉、弹层、搜索框、页签、筛选后不重叠、不裁切、主操作可点击|
|LAYOUT-05|控件状态|默认、选中、禁用、悬停及展开状态清晰；目标模板有主题功能时再分别检查各主题|
|LAYOUT-06|无 JS|390/1280 下正文、导航和真实链接仍可读可达；JS 专用能力单列说明|
|LAYOUT-07|单 H1 与主内容|每个真实页面有且仅有一个主 H1，主内容不是空壳|

## E. SEO 与代码边界

|编号|检查|通过条件|
|---|---|---|
|SEO-01|动态 TDK|title、description、keywords、canonical 与当前页面/站点配置绑定，非首页硬编码|
|SEO-02|内容语义|标题层级、图片 alt、内链、分页、robots、JSON-LD 与真实内容一致|
|SEO-03|直播站链接 nofollow|直播内页中跳转直播站的 `/play/<type>/<id>` 链接均含 `rel="nofollow"`；`target="_blank"` 时同时保留 `noopener noreferrer`|
|CODE-01|变更范围|仅授权模板目录；不改 Python、后端、共享资源或其他模板|
|CODE-02|提交交付|`git diff --check` 通过；提交、远程 SHA、测试报告和问题清单相互对应|

## F. 问题处理与最终判定

1. `TemplateNotFound`、模板异常、错误链接或参数属于前端，修复后重跑受影响页与共用组件宿主。
2. `run.py`、`cache/`、`api/`、数据库或外部数据异常列为 Rechard 问题；每条按 [问题交接模板](TEMPLATE_ISSUE_HANDOFF_TEMPLATE.md) 落盘。
3. 报告结论只能是 `pass`、`fail`、`blocked`、`needs_review`。后端问题、缺样例、未执行测试不计通过。
4. 仅在当前真实入口检查、功能、加载完成布局、动态内容和代码边界均有证据后，才可标记“待人工验收”。人工验收、合并、部署、上站和收录另记。
